# Чек-лист миграции с MongoDB на Strapi

## ✅ Этап 1: Подготовка Strapi проекта

- [ ] Установить зависимости в `strapi-backend`
- [ ] Настроить `.env` файл с секретными ключами
- [ ] Запустить Strapi: `npm run develop`
- [ ] Создать администратора в http://localhost:1337/admin
- [ ] Создать API Token в Settings > API Tokens
- [ ] Проверить, что все Content Types созданы

## ✅ Этап 2: Миграция данных

- [ ] Установить зависимости для миграции: `npm install mongoose axios`
- [ ] Настроить переменные окружения для миграции
- [ ] Запустить скрипт миграции: `node migrate-to-strapi.js`
- [ ] Проверить, что все данные перенесены в Strapi
- [ ] Проверить связи между записями

## ✅ Этап 3: Обновление фронтенда

- [ ] Создать файл `src/lib/strapi.ts`
- [ ] Создать файл `src/lib/strapi-types.ts`
- [ ] Создать файл `src/lib/strapi-services.ts`
- [ ] Обновить `src/app/page.tsx` для работы с Strapi
- [ ] Обновить `src/app/[venueId]/[eventId]/page.tsx` для работы с Strapi
- [ ] Обновить все компоненты, использующие MongoDB данные

## ✅ Этап 4: Обновление переменных окружения

- [ ] Удалить `MONGODB_URI` из `.env.local`
- [ ] Добавить `NEXT_PUBLIC_STRAPI_URL=http://localhost:1337`
- [ ] Добавить `STRAPI_TOKEN=your-strapi-api-token`

## ✅ Этап 5: Удаление MongoDB зависимостей

- [ ] Удалить `mongoose` и `mongodb` из `package.json`
- [ ] Удалить файл `src/lib/dbconnect.ts`
- [ ] Удалить все файлы из `src/model/`
- [ ] Обновить импорты во всех файлах

## ✅ Этап 6: Тестирование

- [ ] Запустить Strapi: `cd strapi-backend && npm run develop`
- [ ] Запустить Next.js: `npm run dev`
- [ ] Проверить главную страницу
- [ ] Проверить страницы событий
- [ ] Проверить все компоненты
- [ ] Проверить загрузку изображений
- [ ] Проверить работу карусели

## ✅ Этап 7: Оптимизация

- [ ] Настроить кэширование для API запросов
- [ ] Оптимизировать запросы с populate
- [ ] Настроить права доступа в Strapi
- [ ] Настроить CORS для продакшена
- [ ] Добавить обработку ошибок

## ✅ Этап 8: Продакшен подготовка

- [ ] Настроить PostgreSQL или MySQL для продакшена
- [ ] Обновить переменные окружения для продакшена

- [ ] Добавить мониторинг и логирование

## 🔧 Полезные команды

### Strapi
```bash
# Запуск в режиме разработки
cd strapi-backend && npm run develop

# Сборка для продакшена
cd strapi-backend && npm run build

# Запуск в продакшене
cd strapi-backend && npm run start
```

### Next.js
```bash
# Запуск в режиме разработки
npm run dev

# Сборка
npm run build

# Запуск в продакшене
npm run start
```

### Миграция
```bash
# Установка зависимостей для миграции
npm install mongoose axios

# Запуск миграции
node migrate-to-strapi.js
```

## 🚨 Возможные проблемы

### CORS ошибки
- Настройте CORS в Strapi конфигурации
- Проверьте домены в настройках

### Проблемы с изображениями
- Проверьте права доступа к медиа файлам
- Убедитесь, что URL изображений корректные

### Медленные запросы
- Используйте кэширование
- Оптимизируйте populate запросы
- Используйте пагинацию

### Проблемы с типами TypeScript
- Проверьте импорты типов
- Обновите типы после изменения схемы

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи Strapi и Next.js
2. Убедитесь, что все переменные окружения настроены
3. Проверьте права доступа в Strapi
4. Убедитесь, что API Token корректный
